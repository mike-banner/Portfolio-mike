# Portfolio | Développeur Front-End & WordPress

Portfolio moderne conçu pour la performance, l'accessibilité et un référencement SEO maximal. Déployé sur l'Edge Network de Cloudflare Pages.

---

## 👤 Profil & Expertise
Développeur spécialisé dans la création d'interfaces web ultra-rapides et d'architectures modernes (notamment Headless CMS). 

* **Core Stack** : React, Astro, JavaScript (ES6+), TypeScript, WordPress.
* **Philosophie** : Approche orientée performance (Core Web Vitals), clean code et autonomie technique.

---

## 🛠️ Stack Technique & Compétences

### Expertises Principales
* **Astro** : Génération de sites statiques (SSG) pour un chargement instantané.
* **React & TypeScript** : Création de composants UI interactifs, typés et réutilisables.
* **WordPress (Traditionnel & Headless)** : Développement de thèmes sur-mesure, de plugins, et d'APIs REST / GraphQL couplées à des front-ends modernes.
* **JavaScript / TypeScript** : Maîtrise des concepts asynchrones, manipulation du DOM et logique métier.

### Compétences Secondaires & Transverses
* **SEO & Performance** : Optimisation LCP/CLS/INP, balisage Schema.org, sitemaps dynamiques.
* **Hébergement & DevOps** : Cloudflare Pages, Git (workflow propre), CI/CD de base.
* **Design & Intégration** : Vanilla CSS moderne (Flexbox, Grid, variables CSS), respect des maquettes Figma, accessibilité (a11y).

---

## ⚡ Performances & Objectifs SEO du Projet
Ce portfolio sert de démonstrateur technique pour les recruteurs :
* **Score Lighthouse** : Objectif 100/100 sur Performance, Accessibilité, Best Practices et SEO.
* **Zero JS par défaut** : Utilisation de l'architecture d'îles d'Astro pour n'embarquer du JavaScript (React) que là où c'est strictement nécessaire.
* **SEO natif** : Données structurées JSON-LD (`Person`, `WebSite`), balises OpenGraph, images converties au format AVIF/WebP.

---

## ⚙️ Commandes de Développement

```bash
# Installation des dépendances
npm install

# Lancer le serveur de développement local
npm run dev

# Compiler le projet pour la production (SSG local)
npm run build

# Prévisualiser la compilation locale
npm run preview
```
